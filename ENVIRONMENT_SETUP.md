# Environment Setup Guide

## Quick Start

Follow these steps to get ProjectHub running locally.

## Frontend Setup

### 1. Environment Variables
Create a `.env.local` file in the project root:

```env
NEXT_PUBLIC_API_URL=http://localhost:8000
```

### 2. Install Dependencies
```bash
npm install
# or if using pnpm
pnpm install
```

### 3. Start Development Server
```bash
npm run dev
# or
pnpm dev
```

The application will be available at `http://localhost:3000`

## Backend Setup

### 1. Navigate to Backend Directory
```bash
cd projecthub-backend
```

### 2. Create Environment File
```bash
cp .env.example .env
```

### 3. Configure .env
Update the following in `.env`:

```env
# Application
APP_NAME=ProjectHub
APP_ENV=local
APP_DEBUG=true
APP_URL=http://localhost:8000

# Database (using SQLite)
DB_CONNECTION=sqlite
DB_DATABASE=database/database.sqlite

# JWT Configuration
JWT_SECRET=your-secret-key-here (generated by artisan command)
JWT_ALGORITHM=HS256
JWT_TTL=60

# Mail Configuration (Optional)
MAIL_MAILER=log
MAIL_FROM_ADDRESS="noreply@example.com"
MAIL_FROM_NAME="ProjectHub"

# API Configuration  
API_CORS_ORIGINS=http://localhost:3000
```

### 4. Install PHP Dependencies
```bash
composer install
```

### 5. Generate App Key
```bash
php artisan key:generate
```

### 6. Generate JWT Secret
```bash
php artisan jwt:secret
```

### 7. Create SQLite Database
```bash
touch database/database.sqlite
```

### 8. Run Migrations
```bash
php artisan migrate
```

### 9. Seed Test Data
```bash
php artisan db:seed
```

This creates:
- 3 test users (admin, manager, member)
- 1 test project
- 3 sample tasks

### 10. Start Development Server
```bash
php artisan serve
```

The API will be available at `http://localhost:8000`

## Verify Installation

### Frontend Checks
1. Open `http://localhost:3000` in your browser
2. You should see the ProjectHub login page
3. Check browser console (F12) for any errors

### Backend Checks
1. Visit `http://localhost:8000/api/auth/me` in browser
2. Should return 401 Unauthorized (expected - no token)
3. No connection refused errors

### API Health Check
```bash
# From project root
curl -X POST http://localhost:8000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email": "admin@test.com", "password": "Admin123!"}'
```

Should return a JSON response with auth token.

## Common Issues and Solutions

### Port Already in Use

**Frontend (3000)**:
```bash
# Use a different port
npm run dev -- -p 3001
```

**Backend (8000)**:
```bash
# Use a different port
php artisan serve --port=8001
```

Then update `NEXT_PUBLIC_API_URL` in frontend `.env.local`.

### Database Connection Error

**SQLite File Missing**:
```bash
cd projecthub-backend
touch database/database.sqlite
php artisan migrate
```

**Permissions Error**:
```bash
chmod 664 database/database.sqlite
chmod 775 database/
```

### JWT Secret Not Set

```bash
cd projecthub-backend
php artisan jwt:secret
```

Then restart the development server.

### No Data After Seeding

```bash
cd projecthub-backend
php artisan migrate:refresh --seed
```

**Warning**: This will delete all data and reseed.

### CORS Errors

Check that `API_CORS_ORIGINS` in `.env` includes your frontend URL:
```env
API_CORS_ORIGINS=http://localhost:3000
```

If changed, restart the backend server.

### Cannot Login

1. Verify backend is running: `http://localhost:8000`
2. Verify test users were seeded: `php artisan db:seed`
3. Check backend logs: `storage/logs/laravel.log`
4. Check frontend console for API errors

## Development Tools

### Laravel Tinker (REPL)
```bash
php artisan tinker

# Check users
>>> App\Models\User::all();

# Check roles
>>> App\Models\Role::all();

# Create new user
>>> App\Models\User::create(['name' => 'John', 'email' => 'john@test.com', 'password' => Hash::make('test123')]);
```

### View Database
SQLite database is located at: `projecthub-backend/database/database.sqlite`

Use SQLite GUI tools or command line:
```bash
sqlite3 projecthub-backend/database/database.sqlite

# List tables
.tables

# View users
SELECT id, name, email FROM users;

# View roles
SELECT id, name FROM roles;

# Exit
.quit
```

### Reset Database
```bash
cd projecthub-backend
rm database/database.sqlite
touch database/database.sqlite
php artisan migrate
php artisan db:seed
```

## Production Considerations

For production deployment:

1. **Environment**:
   - Set `APP_ENV=production`
   - Set `APP_DEBUG=false`

2. **Security**:
   - Use strong JWT_SECRET
   - Enable HTTPS
   - Set proper CORS origins
   - Use environment variables for secrets

3. **Database**:
   - Use PostgreSQL/MySQL instead of SQLite
   - Configure proper backups
   - Enable query logging

4. **Performance**:
   - Enable caching
   - Use Redis for sessions
   - Optimize database queries
   - Implement rate limiting

5. **Logging**:
   - Send logs to external service
   - Monitor error rates
   - Set up alerts

## Troubleshooting Checklist

- [ ] Both frontend and backend servers are running
- [ ] `NEXT_PUBLIC_API_URL` is set correctly in `.env.local`
- [ ] Database migrations have been run
- [ ] Test data has been seeded
- [ ] No firewall blocking ports 3000 and 8000
- [ ] No other services using required ports
- [ ] Browser cookies/cache cleared
- [ ] Console shows no errors
- [ ] API endpoints are accessible (test with curl)

## Support

If you encounter issues:

1. Check the troubleshooting section above
2. Review log files:
   - Frontend: Browser console (F12)
   - Backend: `storage/logs/laravel.log`
3. Reset database and reseed test data
4. Clear browser cache and localStorage
5. Restart both servers
